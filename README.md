# ChartView (working name)

A free, modern charting app for technical traders: live candlestick charts, drawing tools, indicators, bar replay with practice trading, and a trade journal. It runs on **Windows** and **Android**. No account, no sign-up, no ads.

> The name is a placeholder and will change. The first public builds are below.

## Download

Go to the **[Releases page](../../releases/latest)** and download the file for your device:

| Device | File | Notes |
|---|---|---|
| Windows (installer) | `ChartView Setup 0.1.0.exe` | Installs like a normal program. |
| Windows (portable) | `ChartView 0.1.0.exe` | Nothing to install. Just run it. |
| Android | `ChartView-android-debug.apk` | Android 7.0 or newer. |

### Installing on Windows
1. Download the installer (or the portable file).
2. Double-click it. Windows may show **"Windows protected your PC"** because the app isn't signed yet. Choose **More info**, then **Run anyway**.

### Installing on Android
1. Download the `.apk` on your phone (or copy it across from a computer).
2. Open it. Android will ask you to allow installs from that app (your browser or file manager). Allow it for this install.
3. Tap **Install**.

These are early test builds. They aren't on the Play Store or Microsoft Store yet, which is why the warnings appear.

## What's inside
- **Live charts** from Binance public market data: candles, hollow candles, Heikin Ashi, bars and area.
- **Drawing tools** with TradingView-style settings: trend lines, Fibonacci, channels, pitchfork, Gann fan and box, rectangles, text, measuring tools and more. Every drawing has line, fill, lock and timeframe-visibility settings.
- **38 indicators**, including moving averages, Bollinger Bands, VWAP, Supertrend, MACD, RSI, Stochastic, order-flow delta and volume profile, plus a script editor.
- **Bar replay with practice trading:** step back in time, place practice trades with stop-loss and take-profit, and review them in a trade journal with an equity curve and CSV export.
- **Price alerts**, multiple charts side by side, light and dark themes, and your layout saved between visits.

## Things to know
- **Needs an internet connection** for market data.
- Practice trades are **simulated only**. The app never places real trades and can't touch your money.
- **Nothing here is financial advice.** Charts and indicators describe past prices and don't predict the future.
- Your drawings, settings and journal are stored **on your own device**. Nothing is uploaded.
- The Android file is a debug build (signed with a test key), so it won't update automatically. To update, install the newer file over it.
